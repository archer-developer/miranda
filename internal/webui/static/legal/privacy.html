Privacy Policy — Miranda

Last updated: August 22, 2026

Miranda is a personal AI assistant built and operated by a single household for its own, private use — it is not a public product, and it is not offered to the general public. Access is limited to individuals the operator has explicitly authorized (household members). This page explains what happens to data when one of those authorized individuals connects a third-party account (such as Google Calendar) to their Miranda user.

Who operates Miranda

Miranda is self-hosted by its operator on infrastructure the operator controls. The operator is the sole data controller for any data Miranda processes. Contact: archer.developer@gmail.com.

What data Miranda accesses

When an authorized user connects a third-party account (for example Google Calendar) via OAuth, Miranda requests only the specific permissions (scopes) needed for the features that user asked to enable — for Google Calendar, this is currently limited to: reading the list of calendars, reading free/busy time, and reading/creating/updating calendar events. Miranda never requests more access than a given integration needs, and never accesses an account the user has not explicitly connected.

How that data is used

Connected-account data is used exclusively to carry out that same user's own requests to their assistant — for example, checking their availability, or creating an event they asked for. It is never used for advertising, never sold, and never shared with any party other than:

  • the third-party service the data came from (e.g. Google, to fulfill the request itself);
  • the AI model provider Miranda is currently configured to use (e.g. Anthropic or Google), solely as needed to generate a reply to that specific request — the same way any AI assistant needs to see relevant context to answer a question.

How data is stored

OAuth access and refresh tokens are encrypted at rest (AES-GCM, under a key held only by the operator's own server) in a private database on the operator's self-hosted infrastructure. They are never logged in plaintext and are not accessible to anyone other than the operator.

Retention and deletion

A connected account's tokens are kept only for as long as that integration stays connected. Any authorized user can disconnect at any time — either by revoking access from their Google Account permissions page (for Google integrations) or by asking the operator to remove it — which deletes the stored tokens immediately. A user may also ask the operator to delete any other data Miranda has stored about them.

Children's privacy

Miranda is a private household tool and is not directed at or knowingly used by children.

Changes to this policy

The operator may update this policy as Miranda's integrations change. The "Last updated" date above reflects the most recent revision.

Miranda — a self-hosted personal assistant. Not a commercial product or public service.
